# library

NiceGUI-based interface for adding, editing and searching references to articles
and books. Data is stored in Markdown with YAML frontmatter.


## Software

This code has been lovingly hand-crafted. No AI tools were used in its development.

Written in [Python](https://www.python.org/) using:

- [NiceGUI](https://nicegui.io/)
- [PyYAML](https://pypi.org/project/PyYAML/)
- [bibtexparser](https://github.com/sciunto-org/python-bibtexparser)
